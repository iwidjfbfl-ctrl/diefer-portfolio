# Diefer Portfolio (v4)

Portfolio profesional de **Diefer Rodríguez** — Técnico Informático · Estudiante ASIX · Vallirana (Barcelona).

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Lucide React
- Framer Motion (disponible)
- Bun / npm

## Diseño

Neo-brutalist / studio grid: bordes 3px, sombras hard offset, Syne + Space Grotesk, acentos amarillo `#FFE600` y rojo `#FF2D2D`, dark/light mode.

## Scripts

```bash
# Instalar
bun install
# o
npm install

# Desarrollo
bun run dev

# Build + preview (recomendado para túneles)
bun run serve
```
